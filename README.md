# Pokémon Sovereign Complete: progress

The progress page of Sovereign Complete (Johto and Kanto joining Sovereign Platinum), published at
https://hanktwichell.github.io/pokemon-sovereign-progress/. It's built from the game's repository by
`tools/complete/progress_page.py` and replaced whole on each update by `tools/complete/publish_pages.sh`: edits made
here are overwritten.
